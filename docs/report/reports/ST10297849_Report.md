# **<u>HustleHub+ Frontend</u>** 

The frontend for HustleHub+ is built using react, with the following implemented: authentication flow, role based routing, gig browsing, booking confirmation and a full 45 suite of tests that can run against a built in mock adapter that was put in place to run the front end without backend dependency. 

## <u>Tech Stack</u> 

- React 18+ 

- Vite 5 

- React Router v6 

- Zod for form validation 

- DomPurify for html sanitization 

- Vitest 2 

- React Test Library 

- Jsdom 

## <u>Architecture</u> 

AuthContext holds auth state token at the module level via setToken() and getToken() in api/client.js, is Authenticated is derived from the user object. There are three roaute guards that enforce access control, these being: GuestRoute which redirects users to their assigned role pages, ProtectedRoute which will redirect unauthenticated users back to /login and RoleRoute will redirect wrong role users to a not authorized page. Setting VITE_USE_MOCK=true replaces the Axios adapter with built in predefined user environments (details of which will be at the end).

## <u>Security</u> 

Csp-compat.test.js statically will scan all source files and will fail if any use eval, raw innerHTML or dangerouslySetInnerHTML, that fall outside of the approved allow list (sanitize, richtext and gigdetailpage). All of the richtext content passes through DOMPurify before rendering. Forms will validate with Zod before submitting and registerSchema will restrict the role field to z.enum([“client”, “freelancer”]) to try and mitigate privilege escalation. 

## <u>Run Frontend without Backend Dependency</u> 

- cd frontend 

- VITE_USE_MOCK=true 

- npm run dev
